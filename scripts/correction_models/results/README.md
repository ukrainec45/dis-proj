# Артефакти запусків

Реальних результатів нового експерименту ще немає. Вони створюються запуском ноутбуків:

- `main-v1/`: immutable campaign, records, maps, embeddings, sessions, завершений dataset.
- `models-v1/`: навчальні моделі, frozen_run та validation-звіт.
- `test-v1/`: одноразова незалежна оцінка зафіксованого рішення.

Ці файли виключені з Git, але потрібні для відтворення. Пілотні результати старої папки не перейменовуються
на основну вибірку. Синтетичні локальні тести не створюють тут результатів експерименту.
